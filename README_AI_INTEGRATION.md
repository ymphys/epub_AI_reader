# DeepSeek AI 集成说明

## 概述

此项目已将 DeepSeek AI 助手集成到 EPUB 阅读器中，让您可以在阅读书籍的同时与 AI 进行对话，获取章节分析、解答疑问等。

## 新功能

### 1. AI 增强阅读器
- 新的路由：`/read-ai/{book_id}/{chapter_index}`
- 在阅读界面右侧添加了 AI 聊天面板
- 支持实时对话，AI 可以访问当前章节的上下文

### 2. DeepSeek API 集成
- 使用 DeepSeek Chat API
- 自动将当前章节内容作为上下文发送给 AI
- 支持中文对话

## 使用方法

### 1. 设置环境变量

首先，您需要设置 DeepSeek API 密钥：

```bash
export DEEPSEEK_API_KEY="your_deepseek_api_key_here"
```

### 2. 启动服务器

```bash
python server.py
```

### 3. 使用 AI 增强阅读器

1. 访问 `http://127.0.0.1:8123` 查看书籍库
2. 点击任意书籍的 "Read with AI" 链接（或直接访问 `/read-ai/{book_id}/0`）
3. 点击右下角的 🤖 按钮打开 AI 聊天面板
4. 输入您的问题，AI 将基于当前章节内容回答

### 4. 处理 EPUB 文件

如果您有新的 EPUB 文件需要处理：

```bash
python reader3.py your_book.epub
```

这将在当前目录创建 `your_book_data` 文件夹，包含处理后的书籍数据。

## 功能特点

### AI 助手能力
- **章节分析**：分析当前章节的主题、关键概念
- **问题解答**：回答关于章节内容的疑问
- **内容总结**：提供章节摘要
- **背景知识**：解释专业术语和概念
- **阅读建议**：提供进一步阅读的建议

### 技术特性
- **上下文感知**：AI 可以访问当前阅读的章节内容
- **实时对话**：支持多轮对话
- **错误处理**：优雅处理 API 错误和网络问题
- **安全限制**：限制上下文长度以避免 token 限制

## 文件说明

- `deepseek_client.py` - DeepSeek API 客户端
- `templates/reader_with_ai.html` - AI 增强的阅读器界面
- `server.py` - 更新后的服务器，包含 AI 路由和 API
- `reader3.py` - EPUB 解析器（保持不变）

## 注意事项

1. **API 密钥安全**：请妥善保管您的 DeepSeek API 密钥
2. **上下文限制**：每个章节的上下文限制为 2000 字符以避免 token 超限
3. **网络要求**：需要稳定的网络连接来调用 DeepSeek API
4. **费用考虑**：DeepSeek API 调用可能会产生费用，请关注使用量

## 故障排除

### AI 功能不可用
- 检查 `DEEPSEEK_API_KEY` 环境变量是否设置正确
- 查看服务器启动时的日志信息

### API 错误
- 检查网络连接
- 验证 API 密钥是否有效
- 查看浏览器控制台的错误信息

### 上下文不完整
- 如果章节内容过长，AI 可能无法访问完整内容
- 可以尝试询问更具体的问题
